# IT od środka

Seria krótkich pionowych rolek (9:16) na Instagram, w których tłumaczę zwykłe rzeczy z IT:
co się dzieje, gdy klikasz spację w grze, jak działa BLIK, dlaczego strona nie zna twojego hasła,
po co jest 2FA i tak dalej. Każdy odcinek ma 40-60 sekund.

Każdy folder `epNN-...` to osobny odcinek w HyperFrames. Skrypty w głównym folderze:

- `voice.sh epNN-...` lektor (Edge TTS), skrócenie pauz i wyrównanie głośności
- `render-one.sh epNN-... plik.mp4` render jednego odcinka
- `render-all.sh` render wszystkich naraz

Odcinki: spacja, enter, automatyzacja w firmie, BLIK, hasła, Netflix, WhatsApp, szybkość strony,
Google, kody QR, 2FA, chatboty.
